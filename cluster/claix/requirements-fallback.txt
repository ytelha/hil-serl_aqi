# Fallback package list for cluster/claix/setup_env.sh --fallback, used only
# when no lock (pip freeze of the training machine) is available.
#
# It follows serl_launcher/requirements.txt and franka_sim/requirements.txt,
# minus the robot-hardware packages (headless stand-ins in stubs/) and with
# the headless OpenCV build. Two deliberate differences from those files:
#   * mujoco is NOT pinned to 2.3.7: 2.3.7 has no Python 3.12 wheel and was
#     built against NumPy 1.x, while serl_launcher pins NumPy 2.1. The
#     training machine therefore runs some newer MuJoCo; which one only its
#     lock tells. Different MuJoCo versions can change the physics, so
#     fallback results are NOT comparable with the training machine's.
#   * jax is pinned to the version documented in docs/sim_walkthrough.md
#     (0.4.35, CUDA 12), which supports the H100 (sm_90).
